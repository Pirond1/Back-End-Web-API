# Gerenciador de Tarefas 
> Um gerenciador de tarefas simples e eficiente para organizar sua vida e seu trabalho.

![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-blue)
![Tecnologia](https://img.shields.io/badge/Tecnologia-C%23%7C%20HTML%20%7C%20CSS-red)

Este Projeto é um **Gerenciador de Tarefas** desenvolvido para auxiliar na organização de tarefas. Ele permite a criação, edição e gerenciamento de tarefas de forma simples!

Recursos Principais:

-   **Gestão de Tarefas:** Crie, visualize, atualize e exclua tarefas facilmente.
-   **Organização:** Anote e conclua tarefas para manter o controle do seu progresso.
-   **Simplicidade:** Interface limpa e fácil de usar.
